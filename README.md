One brutally honest but still polite out-of-office auto-reply, written by
`main.py` to `/output/entry.txt` for the make.fun bounty
[The Painfully Honest Out-of-Office](https://make.fun/bounty/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b).

## Run

```sh
python3 main.py
```

The entry lands in `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set). It is a single sentence of at most 200
characters: honest about the inbox, warm enough to survive being forwarded
to a manager.
